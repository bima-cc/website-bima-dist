关于我们 ​

北京必码科技工作室（简称"必码"），专注于开源项目定制开发与技术服务。我们秉承"只写必要的代码"理念，围绕企业级身份认证与微服务架构两大核心方向，提供轻量化、可落地的技术解决方案。

我们坚持"小而精、专而深"的服务原则，聚焦开源生态，专注技术落地。凭借丰富的开源二次开发经验，从需求分析到交付运维，全程细致跟进。

核心能力 ​

  • CAS Overlay 单点登录系统：企业级定制开发，支持 WAR 转 JAR 架构升级、JDBC + LDAP 双源认证、OAuth 2.0 + OIDC 协议、Redis 分布式票据、安全加固、前端品牌定制、Docker / CI/CD 容器化部署
  • Keycloak Sandbox 双沙箱：一站式 Keycloak SPI 开发环境，支持多版本 Keycloak、双沙箱环境（Docker 版 + Release 版）、SPI 一键打包发布、内置 SPI 开发示例
  • Keycloak Extension 扩展开发：SPI 用户存储扩展（支持多种数据库）、事件监听器扩展（支持多种消息队列）、国密算法扩展（SM2/SM3/SM4）
  • AI 能力集成：Ollama 本地大模型、OpenAI API、SSE 流式聊天、Chroma 文本向量嵌入等全场景 AI 能力
  • Smart Scaffold 智能中间件集成验证脚手架：一站式微服务脚手架，覆盖 Spring Boot / Dubbo / Spring Cloud 三种架构，集成 MyBatis、Elasticsearch、Kafka、MongoDB、RabbitMQ、Redis、RocketMQ、LDAP 八大中间件
  • 容器化部署：Docker 多阶段构建、Jenkins CI/CD 自动化部署、Kubernetes 编排等容器化部署方案

业务服务 ​

CAS Overlay 单点登录系统 ​

基于 Apereo CAS 提供企业级定制开发服务，解决多系统统一身份认证问题。

核心能力： WAR 转 JAR 现代化升级 · JDBC + LDAP 双源认证 · OAuth 2.0 + OIDC · HTTP + HTTPS 全兼容 · JWT AccessToken · Redis 分布式票据 · 安全加固 · 前端品牌定制 · Docker / CI/CD

查看 CAS Overlay · 阅读 CAS Overlay 深度解析系列

Smart Scaffold 智能中间件集成验证脚手架 ​

一站式微服务项目脚手架，同一业务场景在三种架构下的完整实现，为架构选型提供可直接对比的参考。

核心能力： 8 大中间件集成验证 · AI 全场景集成 · OAuth 2.0 + OIDC · 多数据源动态配置 · 全覆盖测试用例 · Docker / CI/CD

查看 Smart Scaffold · 阅读 Smart Scaffold 深度解析系列

Keycloak Sandbox 双沙箱环境 ​

Keycloak Sandbox 是一个预置了多种扩展功能的 Keycloak SPI 开发环境（Docker /Release 双沙箱），包含用户存储扩展、事件监听器、国密算法等预置功能，可直接体验各类扩展能力。

预置能力： 多数据库用户存储 · 事件监听器扩展 · 国密算法（SM2/SM3/SM4） · 自定义主题 · REST API 扩展

查看 Keycloak Sandbox · 阅读 Keycloak Sandbox 深度解析系列
